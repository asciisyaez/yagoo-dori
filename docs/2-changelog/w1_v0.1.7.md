# Changelog - Week 1, 10-08-2026, V. 0.1.7

**Release Date**: Week 1, 10-08-2026
**Version**: 0.1.7 (previously 0.1.6)
**Object**: fix(board): Board planner page framing and board SVG geometry
**Code review**: user-reported visual defects on the live v0.1.6 planner; root-caused and fixed with before/after screenshot verification on both surfaces; full verification chain + copy audit green on the release commit

## Changes

- **Board SVG geometry (both surfaces)**: the shared grid renderer mapped
  the catalog's signed cell coordinates (x −10..10, y −9..14) into the
  viewBox without offsetting by the minimum, so every negative-coordinate
  node was cropped off-canvas (about half the board, cut mid-node at the
  left and top edges) and the drawn portion huddled in one quadrant with
  dead space below and right. The renderer now derives the offset and the
  viewBox from the actual position extents, so the full 152-node board
  renders complete and centered on the planner and on all talent pages.
  A fixed `min-width` on the SVG element that fought the zoom-scaled
  width attribute (letterboxing at non-100% zoom) was removed.
- **Planner page framing**: the `/holomem-board` route was missing the
  house page container (max-width, centered margin, vertical padding), so
  every section ran full-bleed against the sidebar and viewport edges.
  The page now uses the same container recipe as the Team calculator,
  including its narrow-viewport variant, and the heading is a framed
  hero panel with the tool icon, matching the calculator's hero.
- **Planner layout polish**: the Dream Rank shared-input row and the
  editor's rank/point-mode/extra-points row group left instead of
  scattering across the panel; the editor action row bottom-aligns its
  buttons with the copy-from select; the heading chip hides on narrow
  viewports (matching the calculator's stats behavior).
- **Sidebar icon**: the Holomem Board nav entry has its own node-graph
  icon instead of reusing the Team calculator icon, mirrored in the new
  page hero.
- **Verification**: full AGENTS.md chain green on the release commit;
  Playwright screenshot passes at desktop and 390px-wide mobile confirm
  the complete board, the framed hero, and the contained page on the
  planner, the open Board editor, and the AZKi talent page.
