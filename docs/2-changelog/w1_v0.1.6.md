## Changes

- **Team calculator — search-quality gate closed (Ticket C)**: the three
  named drop-one residuals deferred from v0.1.5 are resolved. The exact
  path now gates on true formation count (team sets × eligible leaders ×
  30 orders vs an effort-profile budget, with the previous 25-set floor
  preserved for back-compat), so small scopes that were needlessly
  bounded are now fully enumerated. Bounded scopes get a screened
  enumerated seed factory (all legal team sets enumerated up to a 200k
  cap, screened coarse → proxy → corpus) plus leader-anchored ascent
  starts that make leader-skill value visible to the search. Full
  128-fixture replay: **0 drop-one violations, 0 Oshi inversions, 0
  budget regressions** (from 102/11/15 pre-upgrade and 3/0/0 at v0.1.5).
  Timings stay inside the user-approved ~12s worst-case budget (observed
  worst ~10.3s thorough). Search telemetry is now tier-separated
  (screened / considered / evaluated), the result contract rejects a
  certified claim that under-reports full-corpus evaluation, and the
  bounded-search disclosure renders whenever evaluation was partial.
- **Team calculator — cross-run consistency (Ticket D)**: each run seeds
  from the previous result, and the seed survives roster, Oshi, and lock
  edits (the previously reported "re-running after a tweak lost my
  team" defect). Constrained runs carry an honest note that re-running
  keeps the better answer. A permanent consistency suite pins the G1
  seed-dominance guarantee, the drop-one/inversion/budget fixture
  classes, and the bounded-path evaluation ceilings in CI.
- **holomem Board planner** (`/holomem-board`, Tools group; T4-T7):
  per-member board editor on the shared 152-node grid (tap/keyboard
  toggle, derived-adjacency arrow navigation that skips dimmed nodes,
  connect-path assist, copy-from, undo), point budgets from Holomem Rank
  estimate or direct entry, and Connect slot picks from owned ★4/★5
  cards. Suggestions run in a dedicated Worker under a reconciling
  contract: budget ledgers, path replay, beam-not-below-greedy floor,
  and cross-board placement uniqueness are all superRefine-verified;
  the response is prose-free (structured effect fields only) with all
  rendered sentences from in-house templates. Claims are explicit and
  machine-carried: bounded suggestion, conditional on the current team
  and declared board state, derived orthogonal grid adjacency, additive
  envelope not jointly attainable; the Connect recommender solves the
  slot assignment exactly on integer micro-units (Hungarian, brute-force
  cross-checked) under the user-confirmed independent connect/unit rule
  with cross-board exclusivity structural.
- **holomem Board on talent pages (T8)**: every talent page renders a
  static board viewer including that talent's own variant effects for
  the three per-talent groups (real values shown, labeled reference-only
  and not evaluated in suggestions). A bulk "auto-unlock by catalog
  priority" action replays the synced `autoSelectionPriority` order —
  deliberately presented as a derived catalog replay, not as matching
  the in-game button, with the affordable-skip and group-ID tie-break
  assumptions declared and regression-pinned.
- **Roster storage v4 with two-writer ownership**: the calculator and
  the board planner each persist only their own fields and preserve the
  other's readable fields verbatim, even under unknown version tags —
  closing two symmetric data-loss defects found in review before they
  shipped. Board state prunes field-by-field against current catalogs on
  data drift (never wiped), with reported prune counts.
