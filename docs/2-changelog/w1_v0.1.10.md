## Changes

- **Product pivot — the Holomem Board surface is retired (owner decision)**:
  the /holomem-board planner page, its components, worker, board web
  libraries, talent-page Board reference section, sidebar entry, sitemap
  entry, and live-smoke route are removed. The Board planning space is
  better served elsewhere; this site's core is the tier list and team
  builder. Deliberately kept dormant: the core board modules and mechanics
  catalogs (inert and tested) and saved Board declarations in roster
  storage (user data stays readable). Copy audit re-baselined for the
  removed sentences.
- **New tool: Roll compare ("Should you roll?")**: pick any unowned Member
  card — searchable, in generation order, deep-linkable via ?card= — and
  compare the saved roster's strongest found team against the team the
  calculator finds with that card added as one fresh copy at Bloom 0. Both
  runs use the same standard search effort, and the saved Oshi and lineup
  locks carry into both, so the comparison is like-for-like. Three honest
  verdicts: the card joins and strengthens the team, joins without
  strengthening it, or does not make the team — with participation counted
  for Member slots and Leader Outfit use alike, a prominent utility delta,
  the displaced/stayed Member diff, and the calculator's own disclosures
  (model utility, not a projected Live Score; Board and Connect effects
  excluded). When either search is bounded, the result says small
  differences should be treated as a tie. Card profiles show a one-line
  entry point for visitors with a saved roster who do not own that card.
- **Quality refactor (four-angle /simplify review, applied)**: the
  calculator and roll-compare now share one module for display formatting,
  required-member normalization, and the saved-Oshi ownership rule; the
  request factory owns the contract schema version; the roster storage
  module owns all parsing of its key; the comparison's eligibility gate
  uses the model's real precondition (five distinct owned talents); the
  baseline run is memoized so repeat comparisons cost one worker run; dead
  CSS and redundant state removed.
- **Copy audit**: 104 occurrences, zero violations, zero unresolved (two
  new allowed-scoped entries for the roll-compare disclosure sentences;
  artifact regenerated with the pivot's removals).
- **Research-track honesty**: the paused exact-timeline shadow evaluator
  module (T1) ships as an inert, non-exported research module with
  hand-calculated tests; no production scoring path uses it.
  `certificateEligible`/`fullRunAuthorized` remain false; X04 remains
  blocked; no ranking, guide, or methodology rebaselined.
