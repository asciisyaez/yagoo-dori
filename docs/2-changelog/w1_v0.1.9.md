## Changes

All nine pass-2 findings resolved; no ranking, guide, team-selection, or
numerical methodology was rebaselined anywhere in this release. The Board
result contract's schemaVersion moved 1 → 2 for ledger disclosure fields
only — Board objective semantics, search behavior, and suggested plans are
unchanged.

- **Pass-2 disposition summary (9 findings)**:
  - **SEO-002 canonical/Open Graph collapse — INVALID_REVIEW_COMMENT**: the
    review claimed every route canonicalized to the homepage; inspection of
    the actual Pages export showed route-specific canonicals on every route
    family (Next.js resolves the layout's relative canonical per route). No
    layout change was made; a permanent pages-e2e guard now pins the
    behavior.
  - **SEO-003 sitemap — fixed**: removed 115 redirect-only Leader URLs, the
    `/leaders/` redirect index, the dead `/synergies/` index, and a dead
    `/sources/` entry the review itself missed (caught by the new guard's
    first run); added the real skills and synergies detail pages. The
    sitemap now lists 546 unique URLs, each verified to resolve to an
    exported page; leader redirect stubs canonicalize to their card target.
  - **A11Y-002 keyboard navigation — fixed**: arrow keys walk the requested
    grid ray per tree model and skip ineligible nodes along the same axis;
    a Down press can no longer resolve to a perpendicular move. Pinned by
    fixtures on all four tree models.
  - **A11Y-004 Board node semantics — fixed**: checkbox role only where
    activation truly toggles an unlock; Inspect-mode and Connect-overlay
    nodes are buttons without checked state; `aria-checked` derives from
    real unlock membership, never visual selection; accessible names are
    unique (group id, kind, effect, cost, lock/gate status).
  - **BOARD-004 direct-mode ledger — fixed (contract v2)**: the per-member
    ledger carries `pointMode` and `directPoints`; the contract rejects
    mode mismatches and per-mode arithmetic violations; direct-mode results
    show a Direct budget instead of inapplicable rank income/extra rows.
  - **WORKER-001 startup failures — fixed (partially valid as reported)**:
    both Worker clients normalize synchronous construction and post
    failures into rejected tasks with idempotent cleanup; the busy state
    always clears and a retry succeeds (proven by an e2e failure drill).
  - **STORAGE-001 silent migration pruning — fixed**: loads that prune
    Board declarations first capture the raw pre-migration record under a
    versioned backup key; the planner shows a one-time notice with
    per-class counts and talent names plus Keep/Restore actions; if the
    backup cannot be confirmed, BOTH the planner and the team calculator
    skip the destructive rewrite — the calculator additionally drops to
    session mode so no autosave can touch the raw record (a Critical gap
    found by Sol in review). Proven end-to-end on both surfaces, success
    and failure paths.
  - **TRUST-001 bare card-profile tiers — fixed**: card pages now label
    tiers as provisional model tiers, repeat the tier page's exact
    benchmark disclosure with index ranges and matched-context counts, and
    link the methodology; the e2e leak guard now requires the disclosure on
    card routes while banning the term elsewhere.
  - **A11Y-003 mobile drawer — fixed**: Escape listens only while the
    drawer is open, closes it, and returns focus to the trigger; the
    trigger's accessible name tracks open/close state.
- **Copy audit**: 104 occurrences, zero violations, zero unresolved (one

- **Research-track honesty**: exact-optimizer scope untouched;
  `certificateEligible`/`fullRunAuthorized` remain false; X04 remains
