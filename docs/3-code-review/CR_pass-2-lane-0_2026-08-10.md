## Finding dispositions

### [SEO-002] Canonical/Open Graph URLs collapse to the homepage — `INVALID_REVIEW_COMMENT`

Empirically refuted before any code was touched: the v0.1.8 pages export
already emits route-specific `canonical` and `og:url` for every sampled route
family (root, cards index, card/talent/guide/skill/synergy details, tool
pages). Next.js resolves the root layout's relative `"./"` per route, contrary
to the review's assumption. No layout change was made. A permanent pages-e2e
guard (`apps/web/pages-e2e/sitemap.spec.ts`) now pins route-specific
canonicals so a regression would fail CI. One adjacent real gap was fixed:
leader redirect stubs canonicalized to themselves; they now claim their
`/cards/{slug}/` target (base path verified intact in the export).

### [SEO-003] Sitemap dead/redirect URLs, missing detail pages — `CONFIRMED_AND_FIXED` (commit `2925ad8`)

Confirmed, plus one miss the review did not catch: `/sources/` was also
advertised with no such route (caught by the new guard's first run).
Fixed: removed `/leaders/` + 115 redirect-only leader entries and the dead
`/synergies/` and `/sources/` indexes; added all skills and synergies detail
pages sourced from the same `generateStaticParams` the routes use. Now 546
entries; the pages-e2e guard asserts uniqueness, base-path correctness, zero
redirect-only families, and that every entry resolves to an exported page.

### [A11Y-002] Arrow keys can move perpendicular — `CONFIRMED_AND_FIXED` (commit `8245c16`)

Confirmed at `board-grid-navigation.ts` (groupId-sorted any-neighbor
fallback). Fixed with same-ray skipping: the walk follows the requested
axis/direction through the tree model's occupied cells, skipping ineligible
nodes, and returns null at the bounds — never a perpendicular jump. The old
test that codified the wrong-direction fallback was replaced with fixtures
pinned from real grid geometry (model-001 down-ray `G-001→G-002→G-005`,
mirrored model-004 right-ray `B-001→B-002`).

### [A11Y-004] Node roles/checked/names — `CONFIRMED_AND_FIXED` (commit `8245c16`)

Confirmed. Checkbox semantics now apply only where activation truly toggles an
unlock (Edit mode outside Connect overlays); Inspect-mode and overlay-pin
nodes are buttons without `aria-checked` (the overlay case was Sol's catch);
checked state derives from real unlock membership, never visual selection;
accessible names are unique and informative (group id, kind, effect summary
via the existing safe label templates, cost, lock/gate status). e2e asserts
role-by-mode, checked-by-membership, and name uniqueness prefixes.

### [BOARD-004] Direct-mode ledger shows rank/extra as operative — `CONFIRMED_AND_FIXED` (commit `8245c16`)

Confirmed. Board contract schema v2: the per-member ledger carries
`pointMode` and `directPoints`; superRefines reconcile each mode's arithmetic
and reject mode/echo mismatches against the declared Board state. Direct-mode
results render Direct budget / Already spent / Remaining / Suggested cost.

### [WORKER-001] Synchronous worker startup failures — `PARTIALLY_VALID_AND_FIXED` (commit `667f505`)

Partially valid as reported: a synchronous `postMessage` throw already
rejected via the Promise executor (not an escaped exception), but leaked the
worker without cleanup; the `new Worker` throw did escape. Both clients now
normalize both failure modes into rejected tasks (`worker-start-failed`,
`worker-post-failed`) with idempotent, null-safe cleanup; `cancel()` is safe
in every state. Unit tests cover both modes for both clients.

### [STORAGE-001] Silent destructive migration pruning — `CONFIRMED_AND_FIXED` (commit `667f505`)

Confirmed. Loads that prune Board declarations now capture the raw
pre-migration record under a versioned backup key with metadata before any
rewrite; the planner shows a one-time dismissible notice (per-class counts,
talent names resolved) with Keep/Restore actions. Stronger than the review
asked: if the backup cannot be confirmed (quota/privacy failure), the
destructive rewrite is skipped entirely — in both the planner AND the team
calculator's hydration path (the latter was a Critical gap Sol found during
review; the calculator-fields autosave was audited and already preserves
stored board fields verbatim). Unit tests cover capture, persistence across
the sanitized rewrite, restore round-trip, and dismissal.

### [TRUST-001] Bare tier badges on card profiles — `CONFIRMED_AND_FIXED` (commit `667f505`)

Confirmed. Card profiles now render "Member · provisional model tier S" /
"Leader Outfit · provisional model tier A" badges plus the tier page's exact
disclosure sentence (byte-matched to the existing ledger entry), per-lens
index ranges and matched-context counts, and a methodology link. The e2e leak
guard was rescoped: card routes REQUIRE the disclosure; every other non-tier
route keeps the `/Provisional/i` ban. New copy-audit ledger entry for the
card-page sentence; audit PASS (104 occurrences, 0 unresolved), artifact
regenerated in the same commit.

### [A11Y-003] Mobile drawer Escape focus — `CONFIRMED_AND_FIXED` (commit `2925ad8`)

Confirmed. Escape now listens only while the drawer is open, closes it and
returns focus to the trigger; the trigger's accessible name tracks open/close
state. The drawer remains deliberately non-modal. e2e covers the full
open→Escape→focus-restored cycle on mobile.
