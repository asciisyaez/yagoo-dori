# N03C: Evidence-linked song and chart contexts

## Acceptance criteria

- [x] Public song metadata is pinned with source URL, upstream version or retrieval time, and transformation notes.
- [x] Exact public fields are kept separate from named parameterized archetypes when note-level charts are unavailable.
- [x] Contexts cover current content plus short, medium, long, combo, Life, and Auto-relevant conditions supported by evidence.
- [x] Cooldown and Special-order duration breakpoints are calculated and tested.
- [x] Every guide result names the exact song or documented context it models.
- [x] Missing note timings or runtime score-equation inputs never become invented precision.
